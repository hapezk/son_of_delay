# 设计文档查看说明

本目录保存 Son of Delay 的机制草案、实现流程和最终复盘，文件采用 Obsidian Canvas 的 `.canvas` 格式。

## 如何打开

1. 安装并启动 [Obsidian](https://obsidian.md/)。
2. 点击“打开本地仓库”。
3. 选择本项目中的 `Design` 文件夹。
4. 在 Obsidian 左侧文件列表中双击 `.canvas` 文件。

请不要把 `.canvas` 当作图片文件打开。它本质上是包含节点文字、坐标和连线的 JSON 文档；GitHub 或 Gitee 只能显示其原始文本，Obsidian 才能还原完整画布布局。

## 当前文档

- `游戏机制.canvas`：最终实现的机制结构、资源系统与开发复盘。
- `流程大纲.canvas`：玩家输入、预览、环形缓冲和权威本体回放的数据流。
- `功能模块设计/核心机制/预览系统.canvas`：三体结构、思考时间预测与预测分歧闪回。

目录中的 `.obsidian` 配置用于保持画布显示习惯；设备相关的工作区状态已由项目根目录的 `.gitignore` 排除。
